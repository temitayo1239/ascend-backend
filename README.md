# ASCEND Backend

AI-powered fitness platform backend built with NestJS, TypeORM and PostgreSQL.

## Features

- JWT Authentication
- User Management
- Swagger API Documentation
- PostgreSQL Database
- TypeORM
- Secure Password Hashing
- Environment Configuration

## Tech Stack

- NestJS
- TypeScript
- PostgreSQL
- TypeORM
- JWT
- Passport
- Bcrypt
- Swagger

## Installation

npm install

## Environment Variables

PORT=

DB_HOST=

DB_PORT=

DB_USERNAME=

DB_PASSWORD=

DB_NAME=

JWT_SECRET=

JWT_EXPIRES_IN=

## Run

npm run start:dev
